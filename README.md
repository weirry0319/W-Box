# 图片批量工具箱 · 使用说明（README）

一个**纯浏览器运行**的图片批处理工具，包含「图片处理」和「批量重命名」两大功能。无需安装任何软件，所有图片都在**本地浏览器**中处理，**不会上传到服务器**。

---

## 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| 浏览器 | **Chrome 或 Edge**（推荐最新版） |
| 联网 | 首次打开需联网加载字体；导入 ZIP 需联网（加载解压组件），其余功能离线可用 |
| 安装 | 无需安装，双击即可打开 |

> ⚠️ 使用「选择文件夹」「覆盖原文件」功能需要浏览器支持文件系统读写 API（Chrome / Edge 支持）。如果用 Safari 或 Firefox，只能拖拽图片文件或 ZIP 使用。

---

## 2. 如何打开

**双击** `图片批量工具箱.html`，选择用 Chrome / Edge 打开即可；也可以直接把文件拖进浏览器窗口。

打开后顶部有两个标签页：
- **图片处理**：改尺寸、转格式、叠加图层、批量导出
- **批量重命名**：给文件夹里的文件/文件夹批量改名

右上角可切换「深色 / 浅色」模式。

---

## 3. 快速上手

### 场景 A：批量改尺寸 / 转格式

1. 顶部切到「**图片处理**」页。
2. 导入图片（三选一，可混合）：
   - **拖入文件夹** 或点「选择文件夹」→ 支持递归读取子目录，推荐用这种方式（可写回原路径）；
   - 点「选择文件」→ 支持多选、可多次追加、支持 ZIP；
   - 直接拖拽图片文件到拖拽区。
3. （可选）在 **模块1** 上传顶层 PNG 图层（水印 / 角标）。
4. 右侧「模块6」设置：
   - **缩放模式**：按像素 / 百分比 / 最长边 / 原尺寸（可一键选 800×800、800×1200、1440×1920）；
   - **输出格式**：原格式 / PNG / JPEG / WebP（JPEG、WebP 可调质量）；
   - **导出方式**：ZIP 打包下载（默认）或 原路径覆盖。
5. 点「**开始批量处理**」，可随时「暂停 / 取消」。
6. 完成后点「**下载 ZIP**」保存结果；若用「选择文件夹」导入并选了「原路径覆盖」，结果会直接写回原文件夹，处理后仍可下载 ZIP 做备份。

### 场景 B：叠加图层 / 水印合成

1. 导入底图（方式同场景 A）。
2. 在 **模块1** 上传一张 **PNG 图层**（保留透明通道，如水印、角标、边框模板）。
3. 右侧「图层拼合」设置：
   - **顶层缩放**：原始 / 宽铺满 / 高铺满 / 拉伸；
   - **对齐位置**：九宫格任选（左上、居中、右下等）；
   - **偏移微调**：X / Y 像素偏移（-500～500）；
   - **不透明度**：10%～100%。
4. 中间 **模块5** 实时预览效果：滚轮缩放、双击复位、放大后可拖拽平移。
5. 确认无误后「开始批量处理」。

### 场景 C：批量重命名

1. 顶部切到「**批量重命名**」页。
2. 点「**选择文件夹…**」并**授权读写**（会记住上次文件夹，下次自动恢复）。
3. 选一种命名规则：
   - **编号命名**：前缀 + 序号 + 后缀，例：`主图01.jpg`（有快捷前缀：主图 / 详情页 / sku / 视频 / 白底图）；
   - **原名加前后缀**：保留原名，前后拼接文字；
   - **查找替换 / 删除**：查找某段文字并替换（替换为空 = 删除），可区分大小写。
4. 选择处理对象：**文件和文件夹 / 仅文件 / 仅文件夹**；按需勾选「保留原扩展名」；设置排序依据（名称或修改时间）。
5. 在「预览」中核对“原名 → 新名”，**红色行表示有冲突，执行时会被自动跳过**。
6. 点「**执行重命名**」，完成后可点「撤销上次」一键回滚。

**快捷键**：`Enter` 执行重命名 · `Backspace` 撤销 · `/` 刷新预览

## 5. 常见问题（FAQ）

**Q：按钮点了没反应？**
用 Chrome 或 Edge 打开；「选择文件夹」类功能在 Safari / Firefox 中不可用。

**Q：GIF 图片能处理吗？**
可以导入，但处理时会按 PNG 处理（会丢失动画）。

**Q：改了格式，文件名会变吗？**
会。输出格式与原来不同时，扩展名会同步改为 jpg / png / webp。

**Q：原路径覆盖会不会把原图弄丢？**
会覆盖原文件，所以**建议先切到 ZIP 导出备份一次**。覆盖后可在本次会话内点「撤销」恢复原图；**关闭页面后无法撤销**。

**Q：上次导入的文件夹 / 模板怎么找回？**
工具会自动记录，点击「恢复上次目录」「恢复定位」即可（需再次授权）。

**Q：我的图片会上传到服务器吗？**
不会。所有处理都在本地浏览器完成，全程不联网传输图片。

---

## 6. 注意事项

- 「原路径覆盖」会**直接修改原文件夹中的文件**，请先备份重要图片。
- 批量处理支持暂停 / 继续 / 取消；取消后已完成的图片仍可下载 ZIP。
- 处理大图或大量图片时，请保持浏览器标签页开启，不要中途刷新或关闭。
- 建议定期清理图片列表（模块4右上角「清空」），避免内存占用过大。
