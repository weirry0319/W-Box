# 图片批量工具箱

一个**纯本地、免安装、不上传服务器**的图片批量处理工具，单文件 HTML，双击就能用。

支持批量改尺寸、叠加透明 PNG 水印/模板、ZIP 打包导出或直接覆盖原文件夹，还能批量重命名。

---

## ✨ 功能一览

| 功能 | 说明 |
|------|------|
| 📐 批量改尺寸 | 按像素 / 百分比 / 最长边，支持保持宽高比 |
| 🎨 顶层合成 | 上传透明 PNG 模板，批量叠加到所有图片上 |
| 📦 ZIP 导出 | 处理完打包下载，保留文件夹结构 |
| 💾 原路径覆盖 | 直接把处理结果写回原文件夹，不用找文件 |
| 📝 批量重命名 | 序号命名 / 查找替换，支持撤销 |
| 🌙 深色模式 | 右上角一键切换 |
| ⚡ 高性能 | 8 路并发，8000 张图也能跑 |

## 🚀 快速开始（30 秒上手）

### 方法一：直接打开（最简单）

1. 下载 `图片批量工具箱.html` 这个文件
2. **双击用 Chrome / Edge 浏览器打开**（推荐 Chrome 或 Edge，其他浏览器可能不支持文件夹读写）
3. 开始使用，不需要安装任何东西

### 方法二：部署到 GitHub（让朋友也能用）

1. 把 `图片批量工具箱.html` 重命名为 `index.html`
2. 上传到你的 GitHub 仓库
3. 仓库 → **Settings** → **Pages** → 选择 main 分支 → 保存
4. 等一分钟，访问给你的网址即可

## 📖 详细使用教程

### 第一步：导入图片

有三种方式把图片加进来：

- **拖进去**：直接把文件夹或图片文件拖到中间虚线框里
- **选择文件夹**：点绿色按钮，选一个文件夹（可以直接覆盖写回）
- **选择多文件**：点白色按钮，选多张图片

> 💡 支持拖入 ZIP 文件，会自动解压处理
> 💡 可以多次拖入追加图片

### 第二步：设置处理参数

右侧"处理设置"面板：

**① 改尺寸（可选）**
- 打开"启用尺寸调整"开关
- 选缩放模式：按像素 / 百分比 / 最长边
- 填宽高，勾选"保持宽高比"避免变形

**② 叠加模板（可选）**
- 左上角上传一张透明 PNG（比如你的 LOGO、边框水印）
- 选顶层缩放模式：原始 / 宽铺满 / 高铺满 / 拉伸
- 用九宫格选择对齐位置
- 拖动 X/Y 滑块微调位置
- 拖动不透明度滑块控制浓淡

**③ 选择导出方式**
- **ZIP 打包下载**：处理完下载一个压缩包
- **原路径覆盖**：直接写回你选的原文件夹（需要用"选择文件夹"按钮导入）

### 第三步：开始处理

1. 点右下角绿色"开始批量处理"按钮
2. 可以随时点"暂停" / "取消"
3. 进度条会显示处理进度，图片列表里会高亮当前处理的那张
4. 左下角日志台会记录每一步

### 第四步：下载结果

- 处理完成后，点"下载 ZIP"按钮
- ZIP 文件名自动是"文件夹名_日期时间.zip"

## ❓ 常见问题

### Q：为什么"选择文件夹"按钮用不了？
A：需要用 Chrome 或 Edge 浏览器。Safari 和 Firefox 对文件夹读写支持不全。

### Q：处理 8000 张图会卡吗？
A：不会。工具用了 8 路并发 + 硬件解码，列表只渲染可见的部分。如果还是慢，可以关掉其他浏览器标签页。

### Q：原路径覆盖安全吗？
A：处理结果会直接覆盖原文件。建议第一次先用 ZIP 导出测试一下效果，确认没问题再用覆盖模式。覆盖前工具会先生成一份 ZIP 备份。

### Q：支持哪些图片格式？
A：JPG、PNG、WebP、BMP、GIF。

### Q：图片会上传到服务器吗？
A：**不会**。所有处理都在你浏览器本地完成，文件不离开你的电脑。

### Q：怎么撤销重命名？
A：重命名页面点"撤销上次"按钮，可以回滚最近一次批量重命名。
