# 图片批量工具箱 · 使用文档

一个纯前端的本地图片批处理工具，单文件 HTML，**所有处理都在浏览器本地完成，不上传服务器**。包含两个功能模块：

1. 🖼️ **图片处理**：批量改尺寸 + 透明 PNG 顶层合成 + 导出（ZIP / 原路径覆盖）
2. 📝 **批量重命名**：编号命名 / 查找替换，支持预览与撤销

---

## 一、运行环境

- 用 **Chrome 或 Edge** 浏览器打开本 HTML 文件即可（双击拖进浏览器都行）
- 需要联网一次加载字体图标（可选，不影响核心功能）
- "原路径覆盖"功能依赖浏览器的文件夹读写能力，**仅支持 Chrome / Edge**
- 无需安装任何软件、无需联网处理图片

---

## 二、快速上手

打开页面后，通过顶部标签栏切换两个工具：

```
[ 🖼️ 图片处理 ]   [ 📝 批量重命名 ]
```

---

## 三、模块一：图片处理（改尺寸 + 合成）

### 整体流程

```
导入底层图片  →  设置（尺寸 / 顶层合成 / 导出方式）  →  开始批量处理  →  下载 ZIP 或自动覆盖
```

### 步骤 1：导入底层图片

有两种导入方式：

| 方式 | 说明 | 是否支持"原路径覆盖" |
|------|------|----------------------|
| **选择文件夹（可覆盖写回）** | 推荐。点击后选择一个文件夹，递归读取其中所有图片（含子目录） | ✅ 支持 |
| **选择多文件 / 直接拖入** | 选若干图片，或把图片/文件夹拖进虚线框 | ❌ 仅能导出 ZIP |

> 支持多次导入追加，自动按相对路径去重。

### 步骤 2：上传顶层模板（可选）

- 在左上角"顶层模板"区拖入或点击上传一张 **透明 PNG**
- 不上传则仅做改尺寸处理
- 上传后可点"更换"替换模板

### 步骤 3：右侧设置

#### ① 启用尺寸调整（开关）

打开后可设置：

- **缩放模式**
  - **按像素**：填目标宽高，可勾选"保持宽高比"；下方有常用尺寸快捷按钮（800×800 等）
  - **百分比**：按原图百分比缩放（如 50%）
  - **最长边**：固定最长边像素，另一边按比例自动计算（常用于压图）
- 关闭则保持原图尺寸，只做顶层合成

#### ② 顶层合成（需先上传模板）

- **顶层缩放**
  - 原始：按模板原始尺寸放置
  - 宽铺满：宽度撑满底层，高度按比例
  - 高铺满：高度撑满底层，宽度按比例
  - 拉伸：强行撑满底层（会变形）
- **对齐位置**：九宫格 9 个位置任选（左上 / 居中 / 右下 …）
- **偏移微调**：在对齐基础上再左右/上下挪 N 像素
- **不透明度**：10%–100%，做半透明水印效果

#### ③ 输出

- **导出方式**
  - **ZIP 打包下载**：处理完点"下载 ZIP"保存压缩包
  - **原路径覆盖**：处理完直接写回原文件夹（需用"选择文件夹"导入），同时 ZIP 仍可下载备份
- **格式**
  - 保持原格式：每张图用自己的原格式输出
  - PNG / JPEG / WebP：统一转成该格式（JPEG/WebP 可调质量）

### 步骤 4：开始处理与导出

- 点底部 **"开始批量处理"**，进度条实时显示进度和当前文件名
- 处理完成后：
  - ZIP 模式：点 **"下载 ZIP"**，文件名形如 `文件夹名_2026-09-19_15-30.zip`
  - 覆盖模式：自动写回原文件夹，提示成功张数；**也可以再点"下载 ZIP"留一份备份**
- 中间预览区会实时显示当前选中图片的合成效果和输出尺寸

## 四、模块二：批量重命名

### 整体流程

```
选择文件夹  →  设置命名规则  →  预览（原名→新名）  →  执行 / 撤销
```

### 步骤 1：选择目标文件夹

点"选择文件夹"按钮授权。该工具会记住上次选择的文件夹，下次打开自动恢复（仍需浏览器授权一次）。

### 步骤 2：设置命名规则

**模式 A：编号命名**

| 参数 | 说明 | 示例 |
|------|------|------|
| 前缀 | 文件名前的文字 | `主图` |
| 起始编号 | 从几开始 | `1` |
| 编号位数 | 前面补零到几位 | 3 位 → `001` |
| 后缀 | 文件名后的文字 | `_a` |

> 例：前缀=主图、起始=1、3 位 → `主图001.jpg`、`主图002.jpg`
> 下方有"主图 / 详情页 / sku / 视频 / 白底图"快捷前缀按钮。

**模式 B：查找替换 / 删除**

- 查找内容：要被替换掉的文字
- 替换为：留空 = 删除该文字
- 可勾选"区分大小写"
- 例：查找 `-` 替换为 `+` → `文件-01.jpg` 变 `文件+01.jpg`

### 通用选项

- **作用对象**：文件和文件夹 / 仅文件 / 仅文件夹
- **保留原扩展名**：默认勾选，改名不动 `.jpg` 等后缀
- **排序依据**：按名称 A→Z / Z→A、按修改时间 新→旧 / 旧→新

### 步骤 3：预览与执行

- 预览表实时显示"原名 → 新名"，**红色行代表冲突**（新名已存在或批次内重名），冲突项会自动跳过
- 点"执行重命名"批量改名；**点"撤销上次"** 可一键回滚上一次操作

### 快捷键（光标不在输入框时生效）

| 按键 | 功能 |
|------|------|
| `Enter` | 执行重命名 |
| `Backspace` | 撤销上次 |
| `/`、`、` | 刷新预览 |

## 五、注意事项与常见问题

1. **"原路径覆盖"有风险**：会直接改写磁盘上的原文件，建议先用少量图片测试，或保留 ZIP 备份。
2. **为什么拖入的图片不能覆盖？** 浏览器安全限制：拖入/多选文件只能读取，无法写回磁盘。要覆盖请用"选择文件夹（可覆盖写回）"按钮导入。
3. **浏览器提示权限**：第一次选文件夹时浏览器会询问读写权限，请点"允许"，否则无法保存。
4. **GIF 图片**：输出时会按 PNG 处理（保留首帧），动画不保留。
5. **文件数量大**：一次处理几百张以上时请耐心等待，进度条会持续刷新；所有计算都在本机，不会上传。
6. **格式转换**：若把格式改成 PNG/JPEG/WebP，文件名扩展名会自动替换；覆盖模式下旧格式文件不会自动删除。

## 六、隐私说明

- 纯前端运行，图片数据不经过任何服务器
- 仅浏览器本地缓存了"上次选择的文件夹句柄"授权，关闭页面后如需再次写入会重新请求权限
- 可随时清空浏览器站点数据清除记录
